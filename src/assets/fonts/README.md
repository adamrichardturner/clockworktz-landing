# Fonts for generated images

TTF copies of the site's fonts, used by `src/lib/og.tsx` to render Open Graph images and icons (the image renderer can't use the WOFF2 files `next/font` serves).

- `Geist-*.ttf`, `GeistMono-*.ttf`: [Geist](https://github.com/vercel/geist-font), SIL Open Font License 1.1 (see `LICENSE-Geist.txt`)
- `InstrumentSerif-Italic.ttf`: [Instrument Serif](https://github.com/Instrument/instrument-serif), SIL Open Font License 1.1
